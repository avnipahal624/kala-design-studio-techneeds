## Processing

The 36 state and union-territory features were simplified locally with Shapely using a topology-preserving 0.018-degree tolerance so the browser asset is approximately 313 KB. Names are title-cased for display. No geometry was hand-drawn or generated by an image model.

## Limitations

This is a web presentation asset, not a legal or survey boundary. Boundary representations can differ between sources and over time. The map is used for craft discovery and should not be treated as an authoritative territorial or legal map.
